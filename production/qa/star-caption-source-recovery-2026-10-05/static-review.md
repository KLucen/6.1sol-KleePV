# Authorized Real Glyph Alternate: Static Review

Scope: native original frames `[1008,1043)`, 35 frames / 16 selected cels. Only
the Japanese word phase `[1037,1043)` uses the alternate donor. This is a
private first-draft proposal, not artistic acceptance or original pixel recovery.

## Why The Old Recovery Was Stopped

The current source cuff and Japanese ink share nearly the same cream RGB.
The old numerical core/outside checks passed but did not establish complete
glyph support. The observed blocker windows were `[846,959,946,988]` and
`[1038,959,1102,988]`; the original hidden stroke alpha remains unobservable.
No further cycles of the same warm-cuff threshold were run.

The complete original source was decoded in two independent sequential scans:
first for recurring visible glyph candidates, then for every frame of the target
and late recurring word ranges. Clear first-letter support at f1037..1043 is
essentially identical (Dice 0.9987..1.0); later third-chorus glyph states differ.
This explains why a stationary common core cannot recover every original stroke.
The donor is deliberately described as an alternate real source glyph state.

## Human Authorization And Donor

Root explicitly relayed the human reply: allow clear subtitle rebuilding first,
then request rework after viewing. The registered real donor is f3402,
`source_refs/src-1905-f3402.png`. Its complete Japanese sentence,
`愛してる 寂しさ2分の1ずつを`, appears over a uniform peach source shape.
No cream cuff, shoe, hair, star line, or black character edge intersects this
donor word. The complete full-size source and word crop were actually viewed.
The saved source crop matches the independent sequential decode exactly.

Each of the 14 real observed glyphs is recorded separately in
`authorized-alternate-glyph-provenance.json`, including source/destination bounds.
One integer-only line registration maps original donor origin x688 to target
origin x676: dx=-12, dy=0, scale=1, rotation=0. No morph, glyph resizing, font
rendering, guessed missing stroke, or program-drawn character was used.
Handwritten extrema vary by a few pixels, as permitted; original exact stroke
identity is explicitly not claimed.

Only observed letter alpha is extracted. The peach plate is not copied.
Decoded donor ink is affected by peach-plate chroma, so composition uses the
actual f1037 clear-glyph cream palette, BGR `[209,224,238]`, instead of copying
warm donor-edge pixels onto the brown Klee boots. Alpha, plate and antialiasing
are reconstructed. Donor-plate reconstruction mean absolute BGR error is 1.544.
The dark/purple/brown glyph-only previews were viewed and contain only readable
Japanese glyphs, no character/background rectangles.
