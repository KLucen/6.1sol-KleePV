# 可莉 PV 制作经验与检查点

本文件记录已发生过的失误及下一次处理办法。每轮生成前读对应镜头条目；每轮结束保存原稿、参考职责、完整 prompt、版本、整图差值和拒收原因。`generated`、`selected_draft`、`static_reviewed`、`artistically_accepted` 是不同状态。

当前用户约定：在保证关键结构、动作、遮挡、文字和原片节奏的前提下优先完成全片；用户观看完整首版后指定返工位置，再定点修改。非阻断细节不再触发反复局部重绘或全片导出。执行步骤与质量门槛见 [PRODUCTION_WORKFLOW.md](PRODUCTION_WORKFLOW.md)。

## 原稿与时间轴

1. **相似画面被当作同一稿。** 低整体差值会漏掉眼皮、衣褶和手势变化。只在对齐后的全分辨率人物区域、局部 RGB 差、轮廓叠图都经过人工核对后登记原稿别名；别名只批准原稿复用，不批准可莉绘稿质量。f671→f682/f720 的真实原片刚性运动有专门证据。
2. **能播放的片段仍可能错拍。** 只按 24 fps 均匀推算会偏离原片毫秒量化的 PTS。曝光表使用逐帧原 PTS；导出后逐项验证帧数、PTS、片尾曝光、AAC 原始包及起点预卷。技术通过仍需实际速度的美术检查。
3. **镜头族名称误导构图。** f2782 被标成 `dive_prone`，实际是站立侧身抱竖枕。先看当前原稿和前后稿，再使用族标签；标签只用来查找候选，不能决定姿势。

## 生图与返修

4. **参考图把当前动作冻成前一稿。** 当前原片决定镜头、人物界限、头角度、四肢、嘴眼和遮挡；身份参考只决定可莉的发色、两束短辫、尖耳、帽与服装。提示词逐图写明职责，并对照当前原稿的头部局部及前后二维差值。f1314/f1329/f1347 的倾斜方向各不相同。

2026-10-04第二批补充：f981明显低头、f987转向镜头、f993抬头睁眼时，改用不含整张脸部姿态的帽/发根/领型位图裁切，当前原稿和二维差值决定新姿势。f981初稿方向正确但下移约18%画布、源动作约10%；仅一次幅度修正后保留剩余近似位置待原速复核，错误初稿不传给后续稿。动作方向正确不等于幅度正确，也不能声称定向编辑锁住其他像素。
5. **红眼修复丢掉瞳孔。** 对两只眼分别查虹膜上缘是否仍蓝、黑色瞳孔钩、白色高光、眼皮斜率和视线。f1380 的仅换红色返修丢过黑瞳与白缺口；颜色合格不等于表情合格。
6. **额外的手、装饰和衣服细节反复出现。** 每张先写遮挡次序与手数，尤其抱枕、举钟、交叉手臂；同镜头连续稿核对恰好两束短辫、帽羽、袖口、领结、靴子和背包。f1497 的手必须藏在交叉袖后，f167 曾多出肩球。
7. **局部返修改坏整图。** 一次只针对一个可测缺陷，比较整张图和目标框外差值。最多两次同方向局部返修；姿势仍错就从当前原稿重新作画，保留未通过版及原因。f157 的手部返修曾在目标区外改动十余万像素。

## 分层合成

8. **人物边缘、多人或转场被漏换。** 每张原稿清点所有可见人体和边缘碎片。`blank_transition` 不代表空镜，f3055/f3067 有明显背影；空镜复用只用于人工确认无人（如 cel0064）。多人物分别记录前后层级。

本轮f900/901补充：巨大背影后只露出的蓝色动物帽双耳，原稿与已生成candidate028 PNG都存在。不能因为前景可莉完整、通用mask通过就漏掉后方原人物；先区分错误在PNG还是合成，再一次重绘整个可见片段及压缩边缘，检查所有实际曝光。单独抓每个人脸仍会漏掉这种全脸被挡住的角色。
9. **道具像素对了，拿道具的手仍错。** 先修人物与枕、钟、鱼、袋的接触位置，再从当前原片分离道具及其前景手指。已登记的悬浮时钟规则不能套到手持时钟；遮挡关系在全尺寸检查。
10. **歌词笔画和标题被人物掩膜吃掉。** 字幕属于原片独立图层。按镜头登记文字区域与前后关系，恢复完整笔画和抗锯齿；与可莉相交时提取透明笔画，避免复制原背景形成色边。前段 f250、f300、f500、f560 是已复现的损坏点。字幕缩放时字体位置会跳变，f290 的原字比前后稿更高；奶白笔画 hue 可低到 12，不能只查一种白色。文字框还要查新旧人物是否进入，f250 的可莉衣袖和 f394 的旧发丝都不能被整块背景恢复覆盖。标题须按无字、标题、署名三个原片相位选择背景板。
11. **旧发丝的空位被纯色抹平。** 全局 HSV 人物掩膜、单色填充和黄色特效膨胀会破坏渐变、星星或把旧皮肤带回。每镜头限定人物范围，清板区分原片可观测像素与重建像素；逐帧审旧/new 人物边界和特效前后层。

## 验收与进度

文字复核补充：不能只统计原片缺失笔画，还要检查新增的错误文字和最终画面的可读对比。f290 的对白框曾多出“好起来”，原字完全恢复仍会漏检；只在确认无人进入的当前对白框内恢复原片底色和文字，禁止扩大到邻近头发。f661 的长腿曾穿过奶白歌词，即使透明笔画没有紫边也读不清；先按当前原稿修人物的腿/靴范围，不能用改字色掩盖姿势错误。

12. **预览通过解码却仍有跳动。** 单稿查结构和原稿姿势，连续原始帧查曝光边界、循环、道具与遮挡，再按原速看完整片。缩小接触图、区域像素相等、精确 PTS/AAC 各自只证明技术的一部分；三层都通过后才标记 `artistically_accepted`。
13. **旧审计数字被当成当前进度。** 每次合并私有候选后刷新覆盖报告、复查有效别名和损坏清单。覆盖率表示草稿可用帧，不能表述为完片率；任何缺稿都不得用邻稿定帧、光流或形变伪装为原稿。

本轮局部返修实测：f58 短辫色修复在目标框外仍有 14899 个像素变化大于 28，f75 手套色修复框外为 42321。这两张虽改善了目标部位，不能声称其余像素保持不变，仍需相邻稿检查；不继续用重复小修来追求整图像素锁定。

舞蹈段补充：f831/f835 的整张邻稿曾把上翘发束、偏侧脸和缺失的正面帽徽一起传给下一稿。只写“身份参考”仍会继承这些错误；明确删去错误邻稿，改用当前原片头部和不含头发的帽饰裁切，再检查前转身幅度、恰好一根帽羽及两束短辫。f835 已进行一次原稿主导重绘，手指、领口和腿靴仍不等于通过。

f848 的 C 形嘴曾被画成吐舌，后折腿也容易沿用前踢稿。当前原片头部放大负责嘴/眼，二维差值负责前踢转后折；用一次原稿重绘解决，拒收版不作后续姿势参考。f839 手套修复归一到 1920x1080 后，目标手部多边形以外仍有 13849 个像素变化大于 28，不能声称整图锁定。

缺陷统计也要回归：不同 worker 的 `static_review.flaws`、根任务的 `known_issues` 及显式选择的 `known_issues` 都必须进入待修清单，不能因 JSON 字段不同而漏计。旧失败选择如果已有有效原稿别名覆盖，保留历史失败记录，但不再计作当前缺稿；有效别名不代表美术通过。

下一批工作顺序：看当前原稿与相邻二维差值 → 写姿势和遮挡清单 → 单稿生成及整图差值 → 选草稿但保留缺陷 → 同镜头连续帧和原速复查 → 道具/字幕/特效分层检查 → 技术与美术状态分别记录。

舞蹈字幕合成补充：宽范围的淡色提取会把旧裤脚/鞋缘当作前景恢复；先检查实际合成的字区外边缘，再关闭该镜头底部的通用提取，只恢复已登记的透明字层。已经可观测的当前原帧字芯直接保留 RGB，不能用统一奶白色替换到产生偏色；抗锯齿与遮住的底板仍记为重建。稳定供体子集的像素通过不代表全部日文字形、星形交点或最终对比度通过，未分类暖色候选必须单列。

14. **字幕相位漏登记会逃过“通过”的报告。** V7 的 831..862 字层与登记区域检测通过，但 812..830 的“我爱你”不在检测范围，编码复核才发现碎笔。完整导出前必须逐一看所有本轮优选稿的实际合成与字幕相位边界，不能只看三张代表稿或原始人物稿；每个检测字段同时写覆盖区间和未覆盖区间。先确认该相位新旧人物均不进字框，再精确恢复安全字区，不把规则倒推到810/811的巨脸镜头。

15. **只关底部通用淡色前景仍会带回旧衣服。** 831..886 没有左侧歌词，旧奶白衣袋/轮廓也会被 `small_left_caption` 当作字幕，在新红衣上留下小白点。先核对该相位真正的前景：此段只保留黄色特效，歌词独立登记，未编辑星星沿用原帧。新增实际合成回归测试强制注入错误左字候选，验证不能恢复旧衣服；不能把此规则全局套到有左侧歌词的镜头。

16. **参考裁切太窄或含错结构都可能延续发型/衣领错误。** f863 只用帽饰参考时保留了腰间长后发；一次限定修复缩短后，后续 f868 仍从另一个未认可整稿继承长后发。f873/f880 又继承多瓣领和分叉衣摆，尽管 prompt 已写禁止。下一次身份参考应从正确的短辫连接、两瓣领及连续衣摆分别建立明确锚点，并在当前姿势整稿中验收；未通过整稿不是可靠结构模板。不无限重复同一小修，也不将文字约束当成已经执行。

17. **延长字幕区间必须重做新增帧审计。** 831..862 的 32 帧结果不证明 863..886 的 24 帧。V8 新增来源逐帧解码、哈希和偏移检查，生产审计明确为 56 帧；旧 `all_32` 仅指原始子区间。暖色候选超出供体 alpha 的 63..2775 个像素仍含原靴与未分类星形/日文交点，不能为数字清零而扩张字形或复制旧鞋。

## 本次提速与交付约定

18. **连续前段长度被当作全部进度。** 36.958秒只表示片头到首个缺稿前的连续区间，现有草稿实际已分散覆盖2323/3658帧（63.5%）。每批同时报告唯一源稿覆盖、全片帧覆盖、连续前段、阻断问题与复核状态，不再用前段秒数代表所有工作。

19. **图片库存被当作独立动作稿，重复版本又占用生成预算。** 本次索引核对为472张PNG：360张被最终映射引用，110张是已覆盖cel的其他版本，2张是辅助素材。未发现可直接补324个缺口却遗漏的现成独立稿。生成前先查cel对应库存和所有曝光；已映射稿默认不再生新版本，未选版本不是自动废稿。

20. **验收占位值制造了错误的低进度印象。** 原审计写死的“通过0”不是逐稿判废结果。明确记录的美术通过、未通过/待验收、没有记录必须分别统计；选稿、技术验证与用户反馈不能互相冒充。没有记录的状态应显示未记录，而不是自动不合格。

21. **边补缺边追求局部定稿，反复停在前段。** 新流程先区分阻断缺陷与非阻断细节。漏换人物、多余肢体、关键姿势错误、严重连续跳变、不可读或破碎字幕、时间轴和声音错误即时处理；轻微线条、少量装饰位置及不影响身份/动作的服装细节进入待修清单，完整首版交付用户后按指定位置返工。关键缺陷不能借提速名义放行。

22. **每补几张就重导、重审整段，验证工作重复。** 每批先检查新增稿、相邻边界、涉及的遮挡/文字层与原速局部；未改合成代码时不反复跑全部代码回归，未改的稿与图层沿用带哈希的既有证据。改公共规则时仍跑受影响回归和所有适用区间。完整全片导出和最终帧/PTS/AAC检查集中执行，不能跳过。

23. **可独立的工作被串行执行。** 按现有work_packages分配所有权：同一cel及其重复曝光只由一个包负责，不同镜头可并行准备原片/差值/提示词、生成和检查；同镜头相邻稿仍遵循端点依赖，不拿未通过的错误发型或服装当身份锚点。工具可用性或额度失败不能靠反复重试、切换未经授权通道来提速。

24. **把保守拆分上限当成必需重画数量。** 689是当前保留cel上限，不是689张都已确认必须独立重画。补缺前按当前原图、局部RGB差和轮廓验证真正重复的稿；只有证据足够的来源别名才复用，疑似相似不能自动合并，更不能以定帧、镜像、光流或morph补缺。

25. **用户反馈后仍需保持可追溯、局部返工。** 完整首版固定文件哈希、时间轴、稿件选择和版本，待修项带帧号/时间码/cel与类别。用户指出问题后只改相应稿及其全部重复曝光，复查邻稿、循环和关联道具/字幕；保留其余已认可内容，避免整片重生成或回退旧版本。

26. **人物转场不等于字幕换词。** 本轮实际源 f831..896 仍是“两人在世界角落起舞”，真正换词在 f897。每个词相位独立登记真实供体及曝光；f911/f914/f919 可以只供字幕，不表示它们的人物或后续曝光已经验收。不能沿用旧字层到新词相位，或把镜头族名称当作字幕边界。

第二批侧脸97帧顺序核对发现真正短词边界是f966，不是f967；它位于cel0189的[965,967)人物曝光内部。原f967提交prompt中的错误推断原文保留，另加事后纠正记录，不隐瞒历史。字层按actual frame独立切换，人物曝光不增加；97帧字形位置搜索均以(0,0)唯一最优，字幕不随人物刚性矩阵变形。

27. **暖色与改写区域都不是字幕/新人物的充分证据。** 巨脸肤色可能满足 warm 字芯阈值，旧衣边也可能成为 pale 候选；需要真实字形供体支持和接近字色。output!=source 还包含旧人移走后的背景，不等于可莉覆盖。固定窄对比边只作用实际 new_subject、真正字形支持和低对比亮底，保留字芯 RGB，声明新增边缘并区分重建与源像素。

28. **没有检测字段的镜头可能得到空集合“通过”。** 举臂镜头 f1225..1284 不属于既有 opening/dance/title 字幕检测，通用检查全为真不证明其歌词保存。批末必须看本镜头实际合成和最终编码文字；未登记的相位显式列为未覆盖。发现同类丢字时修一个相位规则及所有受影响曝光，不给每张 PNG 反复做独立文字修补。

29. **蓝色人物和蓝色背景不能共享通用 sky 判定。** 夜景过渡中 cyan 人物被 HSV sky 误分，既截掉新帽/人物外缘又残留原绿轮廓；vacated 区直接拷生成蓝背景还会破坏原渐变。使用本镜头注册的新旧轮廓和有来源的局部清板，保留未编辑源星月，不全局扩大人物区域或填纯蓝。原人物残留与背景接缝属于合成阻断，不应靠重复生图修。

第二批侧脸补充：原长发被画布底边裁切，若从底边向内播种“天空”，高饱和蓝色头发阴影会变成与外部相连的空背景，留下旧发丝/脖子。此镜头旧人物天空连通只从已确认的上/右背景边界进入；生成稿使用独立matte，并排除短辫之间封闭的亮蓝空隙。旧人移走后的天空取原片可见渐变重建，重建部分明确标记，不能用生成天空或纯色清板冒充源像素。新规则回归此前舞蹈/举臂74帧合成BGR哈希不变。
